## Layer Summary

- `BASE`: normal typing, home-row mods, thumb access to the main layers
- `NAV`: arrows, page movement, insert/delete, and mouse on the 5-way switch
- `NUM`: Miryoku-style numbers, plain modifiers on the left home row, and a path into `NAV`
- `CODE`: rolls-first coding symbols for brackets, operators, and punctuation
- `UTIL`: Bluetooth, RGB, output switching, bootloader/reset, and function keys

## macOS Notes

On macOS, the modifiers in the keymap mean:

- `GUI` = `Command`
- `Alt` = `Option`
- `Ctrl` = `Control`
- `Shift` = `Shift`

The base layer uses home-row mods:

- left hand: `A=Command`, `S=Option`, `D=Control`, `F=Shift`
- right hand: `J=Shift`, `K=Control`, `L=Option`, `;=Command`

There is also a dedicated `GUI` thumb key, which is usually the easiest `Command` key for macOS shortcuts.

## Thumb Cluster

Current thumb plan:

- left outer: `GUI`
- left middle: tap `Tab`, hold `NAV`
- left inner: tap `Space`, hold `NUM`
- right inner: tap `Enter`, hold `CODE`
- right middle: `Backspace`
- right outer: tap `Option`, hold `UTIL`

## Utility Layer Reference

The `UTIL` layer contains the low-frequency controls that are hard to infer from the SVG alone.

Bluetooth:

- `BT_CLR_ALL`: clear all stored Bluetooth profiles
- `BT_CLR`: clear the current Bluetooth profile
- `BT_SEL 0` to `BT_SEL 3`: switch to Bluetooth profile slots 0 to 3

RGB:

- `RGB_OFF`: turn underglow off
- `RGB_ON`: turn underglow on
- `RGB_EFF`: next RGB effect
- `RGB_EFR`: previous RGB effect
- `RGB_BRI`: increase RGB brightness
- `RGB_BRD`: decrease RGB brightness

Output and maintenance:

- `OUT_USB`: force USB output
- `OUT_BLE`: force Bluetooth output
- `Studio Unlock`: unlock ZMK Studio access
- `Bootloader`: enter firmware flashing mode
- `Sys Reset`: reboot the keyboard firmware

Other `UTIL` keys:

- `F1` to `F12`: function keys
- `Mute`: consumer mute key
- encoder rotate on `UTIL`: RGB brightness
- encoder press on `UTIL`: play/pause

## Diagram Legend

Some labels in the keymap diagram are easy to miss if you have not used ZMK before.

- `h:` means the key's hold behavior
- `s:` means the shifted symbol printed on that key
- `Trans` means `transparent`, so the key falls through to the layer below
- the `alpha-w-box` icon is `Caps Word`
- the backspace icon means `Backspace`
- the reversed backspace icon means `Delete`
- the mouse-arrow icons on the 5-way switch mean mouse movement on that layer

Board-specific behavior:

- left encoder rotate: volume on `BASE`, scroll on `NAV`/`NUM`/`CODE`, RGB brightness on `UTIL`
- left encoder press: `Space` on `BASE`
- right 5-way switch: arrows on `BASE`, mouse movement and click on the other layers
